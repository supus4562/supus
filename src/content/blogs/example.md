# System Override

Testing is fundamentally flawed because it only proves the presence of bugs, not their absence. We need to focus on **formal verification**.

## Why?
Because at 2 AM, the last thing you want is a segfault.

- Math works.
- Code fails.
- Therefore, make code math.
